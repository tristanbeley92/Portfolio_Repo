01

The starting point

A genre alone does not describe what someone wants to listen to. This project explores a more interactive way to choose music using both context and individual song selections.

02

What I built

I built a Python and Flask backend around the Spotify Web API, paired with an HTML, CSS, and JavaScript frontend. Users can search genres and select music through a Tinder-style interface to assemble a custom playlist.

03

Under the hood

The backend is the boundary between the browser and the third-party API. Keeping endpoints clear and focused was central to making the playlist flow understandable and maintainable.

04

What stayed with me

Working with a third-party API made planning the request flow as important as building the interface. It also reinforced the value of mapping out the experience before writing the endpoints.
