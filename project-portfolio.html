This little corner of the web

My portfolio started as my first project: a site built with HTML, CSS, and JavaScript. It has become a place to document the work that came after it.

01

The starting point

A portfolio needs to do more than list technologies. Visitors should be able to understand what a project does, what I worked on, and what I learned from building it.

02

What I built

The current version uses standalone HTML pages, a shared stylesheet, and a small JavaScript file. Project write-ups and page templates are maintained in a Python build script that generates the static files.

03

Under the hood

Content is available without JavaScript. Project filters, preview switching, and the command menu are progressive enhancements. Images are compressed WebP files, and motion respects the reduced-motion preference.

04

What stayed with me

The original version taught me the fundamentals of building from scratch. This iteration keeps that lightweight foundation while giving the projects enough space to tell their own stories.
