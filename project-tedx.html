TEDxThirdWard

A public website and a custom admin console for a local TEDx organization. Speakers, events, and stories on the outside; practical content tools for the team behind them.

ReactTypeScriptPostgreSQL

INSIDE THE BUILD01 The starting point02 What I built03 Under the hood04 What stayed with me
01

The starting point

The public site needed to tell the story of the events. Behind the scenes, non-technical team members needed a way to update that content without editing code.

02

What I built

I built the public portal in React and TypeScript, with a separate admin console for managing content. Serverless Node.js functions handle authentication and database operations against PostgreSQL. The application is deployed on Vercel.

03

Under the hood

Authentication uses JWTs and bcrypt password hashing, with forced password rotation for new users. Building the admin interface meant turning relationships between speakers, events, and posts into controls that the team could use.

04

What stayed with me

This project brought stakeholder conversations directly into implementation: volunteer management and admin access requirements shaped both the interface and the backend. The source belongs to TEDxThirdWard and is not public.
